# ROBOT FIGHTER II — The Humanoid Warriors

Jeu de combat HTML5 façon Street Fighter II avec de vrais robots humanoïdes :
Optimus (Tesla), Atlas (Boston Dynamics), Figure 02, ASIMO (Honda), Unitree H1,
Ameca (Engineered Arts), Digit (Agility Robotics), Apollo (Apptronik).

Ouvrir `index.html` via un serveur web (ex. `python3 -m http.server`) puis jouer.

- Écran titre avec les vidéos d'intro, PRESS START, menu Arcade / Versus / Commandes
- Sélection des robots, écran VS, 2 manches gagnantes, chrono 99
- Coups spéciaux (boule d'énergie, uppercut/salto, toupie, ruée) et SUPER avec cinématique
- Effets : étincelles, éclats métalliques, hit-stop, tremblement, ralenti au K.O., combos
- IA progressive en arcade (7 adversaires), clavier 2 joueurs, manette, contrôles tactiles
